# AI FUNDAMENTALS P1 - Search Algorithms

First Practice about applying search algorithms (Breadth First, Depth First and A*) to solve the optimal path problem of a drilling robot

## Folder Structure

```
search-algorithms/
├── input/                    # Folder to place input text files
│   └── random/                   # Random maps generated by the pipeline (created automatically)
├── output/                   # Traces and metrics generated by the pipeline (created automatically)
├── src/                      # Source Code
│   ├── environment/              # Contains the classes that structure the problem
│   │   ├── config.py                 # Config Class - Reads, validates and declares the input
│   │   ├── constants.py              # Constants File - Orientations, moves and names dictionaries
│   │   ├── problem.py                # Problem Class - Actions, transition model, cost and goal test
│   │   ├── state.py                  # State Class - Declares an immutable state (x, y, orientation)
│   │   └── utils.py                  # Utils File - Trace formatting and printing functions
│   └── search/                   # Contains the classes that solve the problem
│       ├── algorithms/               # Contains the implementation of the algorithms
│       │   ├── astar.py                  # A* Class - A* algorithm and its heuristics
│       │   ├── sbf.py                    # Breadth First Search
│       │   └── sdf.py                    # Depth First Search
│       ├── node.py                   # Node Class - Defines the structure of the nodes of the search tree
│       └── randomMapGenerator.py     # PipelineGenerator Class - Generates random maps and runs the comparison
├── main.py                   # Main file to start the execution
└── requirements.txt          # Contains the libraries required for the execution
```

## Steps to execute

# 1.- Clone Repository

Either by GitHub Desktop or by Git Bash

# 2.- Build and activate Virtual Environment (Windows Version)

Python 3.10 or higher is required.

Windows:

```sh
cd .\search-algorithms\
python -m venv aif
.\aif\Scripts\activate
```

# 3.- Install requirements

```sh
python -m pip install -r requirements.txt
```

# 4.- Place Input Files

Input files must be placed in the `input/` folder with `.txt` extension and must follow the specified format, which is the following:

```
Matrix Size
Matrix Map
Start Coordinates & orientation
Goal Coordinates & orientation
```

The character separators must be spaces and the characters must be numbers. Example below for matrix size = (3,3), matrix map = [[3 2 4],[2 3 1],[1 4 2]], start coordinates = (0,0) and orientation = 0 (North), goal coordinates = (2,2) and orientation = 8 (Irrelevant):

```
3 3
3 2 4
2 3 1
1 4 2
0 0 0
2 2 8
```

Note: A hardness of 0 represents an impassable rock that the robot cannot drill

# 5.- Execution

```sh
python .\main.py
```

The execution is configured through an interactive menu. For each question, type the number of the desired option and press Enter. Leaving the answer empty selects the default option.

**Execution mode**: Choose between the two available modes.
- **Solve a map from the input folder** (default): Solves a single map and prints the full execution trace.
- **Run a pipeline on random generated maps**: Generates random maps and solves them with all the algorithms.

### 5.1.- Solve a map from the input folder

**Input file**: Name of the input file placed in the `input/` folder, without extension. The available maps are listed in the menu. Maps generated by the pipeline can be solved by typing `random/` before their name (e.g. `random/randomMap3x3_0`).\
**Algorithm**: Breadth First, Depth First or A*.\
**Heuristic**: Only asked when A* is selected.
- **Weighted Chessboard Distance**: Chebyshev distance multiplied by the minimum hardness of the map.
- **Weighted Manhattan Distance**: Manhattan distance multiplied by the minimum hardness of the map.
- **Null heuristic (h = 0)**: Uniform Cost Search, always returns 0

Note: As stated on the report, the Manhattan heuristic is **NOT** admissible for this problem. It is just implemented as an informative heuristic for comparison purposes

### 5.2.- Run a pipeline on random generated maps

**Seed**: Choose whether to use a specific seed or a random one.

The pipeline performs the following steps:
1. Generates 5 random maps for each of the sizes 3x3, 5x5, 7x7 and 9x9, with start position (0,0) and goal position (N-1, N-1). The maps are saved in `input/random/` (existing files are overwritten).
2. Solves every map with Breadth First, Depth First and A*.
3. Saves the results in the `output/` folder:
   - `pipeline_generator_traces.txt`: Full execution trace of every algorithm on every map.
   - `pipeline_generator_metrics.txt`: Mean depth (d), cost (g), explored nodes (#E) and frontier nodes (#F) of each algorithm for each map size.
